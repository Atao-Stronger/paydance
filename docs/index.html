PayDance 是一款常驻桌面的下班倒计时工具。它按你的工作时间和薪资设置， 实时展示工作进度、距离下班的时间与今日收入。

实时倒计时

按上下班、午休和加班时间计算当天剩余工作时长。

02

收入进度

支持日薪、月薪、补贴、加班收入和个人缴纳金额配置。

03

桌面常驻

提供悬浮窗口、主题、缩放、透明度和日历统计能力。
